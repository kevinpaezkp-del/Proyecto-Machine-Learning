# Estimación de estancia hospitalaria · Proyecto académico

**[Abrir presentación web](https://kevinpaezkp-del.github.io/Proyecto-Machine-Learning/)**

## Propósito
Este repositorio contiene exclusivamente una **versión pública de divulgación académica** sobre modelos de regresión para estimar días restantes de estancia hospitalaria.

Se trabajó con **más de 30.000 episodios históricos**, utilizando un período inicial de referencia, uno posterior para entrenamiento y uno más reciente para evaluación retrospectiva. Se utilizaron ocho predictores conceptuales y validación cruzada agrupada por episodio.

## Qué se puede consultar
- Contexto y objetivo de negocio.
- Fuente conceptual de los datos, sin estructuras internas.
- Características generales de la distribución de estancia.
- Metodología CRISP-DM, selección de variables y validación.
- Comparación académica de modelos con **métricas aproximadas y redondeadas**.
- Límites, errores por intervalos y retos de uso.
- Ejemplos ficticios de un tablero y simulador pedagógico.

## Protección de información
- **No contiene** fuentes de pacientes, registros individuales, censo, cargos, documentos clínicos, identificadores, exportaciones analíticas detalladas ni modelos entrenados.
- No incluye nombres o códigos de GRD específicos, recuentos exactos por subgrupo ni información de sistemas institucionales.
- Todos los números publicados son **cifras aproximadas para divulgación**.
- Los casos del tablero y la simulación son **ficticios**, no representan la ejecución individual del piloto ni son inferencias del modelo real.
- El modelo y los datos originales permanecen en un entorno de acceso restringido.

Esta versión pública no permite reproducir el entrenamiento completo sin acceso autorizado a los datos originales.
